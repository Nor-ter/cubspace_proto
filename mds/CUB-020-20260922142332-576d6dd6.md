## 완료 기준

- AC-1: 한국어 README만 따라 Conda 환경 생성, Node.js 설치, VS Code 열기와 관리자 미리보기를 실행할 수 있다.
- AC-2: 모든 학습 경로가 데스크톱과 모바일에서 열리고 그림의 설명이 바로 아래에 표시된다.
- AC-3: ADCS 수식과 출처를 유지하고 UI 번역, 설명 순서 및 접근성을 개선한다.
- AC-4: ticket.json으로 재현 가능한 작업 Markdown과 실행 기록을 생성한다.
- AC-5: 검사와 독립 리뷰 결과를 코드 버전에 연결하고 Prolog 사실과 티켓 보고서로 남긴다.
- AC-6: 실패 또는 오래된 리뷰가 있으면 커밋과 푸시를 차단한다.
- AC-7: VS Code 에이전트 실행 경로와 ClickUp 가져오기 명령을 문서화한다.
