## 확인 범위와 실행 상태

- NASA 17페이지·UiO 46페이지 PDF를 확보하고 텍스트와 핵심 도식을 확인했다. NASA 일부 수식은 추출 오류가 있어 그림으로 확인했으며 깨진 수식을 그대로 옮기지 않았다.
- Fonod 원문은 처음 링크의 접근 제한 후 같은 TU Delft의 접근 가능한 PDF에서 확인했다. 원문의 연구 주장과 코드의 현재 동작을 구분했다.
- MATLAB 코드 commit `83aaef530307808ef01e46c136f2955ef00cc95b`의 main, main_old, propag_att, kepler2cart, q2dcm 등을 정적 검토했다. 버전은 2026-09-14 조회 결과이며 이후 master와 다를 수 있다.
- MATLAB·Toolbox·Python Engine·Janus 설치 또는 실행은 하지 않았다. 수치 시뮬레이션과 논문 재현은 미수행이다. 자체 제작 세 계산 사례만 산술 확인했다.
- 8개 카드의 A–E 구성, 이미지 연결, 인쇄본 카드/페이지 대응을 확인했다. Prolog facts는 제안 경로이며 실제 Tree로 검증하거나 실행하지 않았다.
- 외부 강의와 영상은 웹 각주 후보다. 실제 재생 시간 구간이나 전체 영상 시청을 검증했다고 주장하지 않는다.
- 원본 PDF/코드는 로컬 sources에 조사 근거로 보관한다. 전달용 ZIP은 자체 작성 문서·카드·기존 앱 캡처·카드 인쇄본만 포함한다.
